```
│   │   ├── serializers.py          ← JSON conversion
│   │   ├── urls.py                 ← All REST API URL routes

│   ├── core/
│   │   ├── settings.py             ← All Django settings
│   │   ├── urls.py                 ← Root URL config (includes media serving)
│   │   └── asgi.py                 ← ASGI entry point (HTTP + WebSocket routing)
│   ├── staticfiles/                ← Auto-generated by collectstatic — do not edit
│   ├── media/                      ← Uploaded files from chat (images, PDFs, avatars)
│   ├── manage.py                   ← Django CLI tool
│   └── db.sqlite3                  ← Local SQLite database (auto-created)
│
├── src/                            ← React (JavaScript) — Frontend
│   ├── pages/
│   │   ├── Home.jsx                ← Public homepage (hero, projects, team)
│   │   ├── Portal.jsx              ← Members dashboard (announcements, chat, profile, admin)
│   │   ├── Contact.jsx             ← Sponsors & contact page
│   │   ├── ProjectBattleBots.jsx
│   │   ├── ProjectRallyCart.jsx
│   │   └── ProjectRobotArm.jsx
│   ├── hooks/
│   │   └── useSocket.js            ← WebSocket hook (real-time chat, typing, reconnect)
│   ├── assets/                     ← Images, team photos, logo
│   │   └── team/                   ← Individual member headshots
│   ├── App.jsx                     ← Route definitions + session restore on refresh
│   ├── Navbar.jsx                  ← Navigation bar (desktop + mobile hamburger)
│   └── index.css                   ← All site styling (dark theme, chat, mobile)
│
├── requirements.txt                ← ALL Python dependencies — install with one command
├── vite.config.js                  ← Frontend build + proxy for /api /ws /media /static
├── index.html                      ← Flaticon uicons CDN loaded here
└── package.json                    ← JavaScript dependencies
```

> **How it works:** React runs on **port 5173**. Django runs on **port 8000**.
> Vite automatically proxies `/api`, `/ws`, `/media`, and `/static` from 5173 → 8000.

## 🚀 First-Time Setup

### Step 1 — Clone

```bash
git clone https://github.com/Angel-A-V/Robotics-Society-UC-Merced.git
cd "Robotics Society UC Merced"
```

---

### Step 2 — Backend

```bash
cd backend

# Create and activate virtual environment
python3 -m venv venv
source venv/bin/activate        # Mac / Linux
# venv\Scripts\activate         # Windows
```

You'll know it's active when you see `(venv)` at the start of your prompt.

**Install all Python dependencies using requirements.txt:**

```bash
pip install -r ../requirements.txt
```

> `requirements.txt` is in the root of the project (one folder up from `backend/`).
> It installs all seven packages automatically — no need to type them individually.

| Package | Why it's needed |
|---------|----------------|
| `django` | Web framework |
| `djangorestframework` | REST API support |
| `djangorestframework-simplejwt` | JWT login tokens |
| `django-cors-headers` | Allows React (5173) to call Django (8000) |
| `channels` | WebSocket support for real-time chat |
| `daphne` | ASGI server — replaces `manage.py runserver`, handles WebSockets |
| `whitenoise` | Serves Django admin CSS/JS through daphne |

**Apply database migrations** (creates all tables):

```bash
python manage.py migrate
```

**Collect static files** (makes Django admin CSS work — run once):

```bash
python manage.py collectstatic
```

Type `yes` when prompted.

Open a **new terminal** in the root folder (not `backend/`):

## 👤 Creating the First Admin Account

The **first person to register** automatically becomes admin.

1. Both servers must be running
2. Go to `http://localhost:5173/register`
3. Register — you're now admin
4. Log in → go to `/portal` → you'll see Announcements, Chat, Profile, and Admin Panel tabs

---

## 🔑 Role System

| Role | Permissions |
|------|------------|
| **pending** | Default after registering. Read-only — view announcements and chat history. Cannot send messages, react, or upload files. |
| **member** | Approved by admin. Full chat — send messages, react with emojis, upload files, delete own messages. |
| **admin** | Everything members can do + approve users, change roles, create/delete channels, post announcements, delete any message, access Django admin. |

Admins approve users from **Portal → Admin Panel → ✓ Approve**.

## 🛡️ Django Admin Access (`/admin`)

Django's admin panel at `http://127.0.0.1:8000/admin` requires `is_staff = True`.

**This is handled automatically** — promoting someone to admin through the portal also sets `is_staff` and `is_superuser`.

**One-time fix for existing accounts** (only if your account was created before this fix and can't log into `/admin`):

```bash
cd backend
source venv/bin/activate
python manage.py shell
```

Type these **one line at a time**, pressing Enter after each:

```python
from api.models import User
```
```python
for u in User.objects.filter(role='admin'):
```
```python
    u.is_staff = True
```
```python
    u.is_superuser = True
```
```python
    u.save()
```
```python
    print(u.username)
```

Press **Enter twice** (blank line ends the loop), then:

```python
exit()
```

Restart daphne. You can now log into `/admin` with the same credentials you use on the website.

## 💬 Setting Up Chat

**Create your first channel** (admin only, done once):

**Option A — from the portal (recommended):**
1. Log in as admin → go to Portal → Chat
2. Click the `+` button next to "CHANNELS"
3. Type a name (e.g. `general`) and optional description → Create

**Option B — from Django admin:**
1. Go to `http://127.0.0.1:8000/admin` → Channels → Add Channel
2. Name: `general`, Description: `This is an overall chat` → Save

**Chat features:**
- Real-time messaging via WebSocket
- Message history persisted to database (loads on channel open)
- File and image uploads — click the attach icon or drag-and-drop
- Attachment preview before sending — add optional text, click Send
- Image lightbox — click any image to view full-size inside the app
- Emoji reactions — hover a message, click the smile icon to react
- Reactions update live for all users instantly
- Typing indicators — shows who is typing in real time
- Users can delete their own messages; admins can delete any message
- Admins can create and delete channels directly from the chat sidebar
- Auto-reconnect if WebSocket drops

**Testing with two users:**
- Browser 1 (normal): log in as admin
- Browser 2 (Incognito): log in as a member
- Both go to Portal → Chat → #general
- Messages, reactions, and typing indicators appear live on both sides

## 🛣️ Backend API Routes

Base URL: `http://127.0.0.1:8000`

All protected routes require:
```
Authorization: Bearer <your_access_token>
```

### Auth

| Method | Route | Auth | Description |
|--------|-------|------|-------------|
| `POST` | `/api/auth/register` | ❌ | Register. Body: `{ username, email, password, confirm_password }` |
| `POST` | `/api/auth/login` | ❌ | Login. Body: `{ username, password }` → returns `access` + `refresh` |
| `POST` | `/api/auth/refresh` | ❌ | New access token. Body: `{ refresh }` |
| `GET`  | `/api/auth/me` | ✅ | Current user's data |

### User Management (Admin only)

| Method | Route | Description |
|--------|-------|-------------|
| `GET`  | `/api/auth/users` | List all users |
| `POST` | `/api/auth/users/<id>/approve` | Approve pending → member |
| `PUT`  | `/api/auth/users/<id>/role` | Change role. Body: `{ role }` → `pending` / `member` / `admin` |

### Profile

| Method | Route | Who | Description |
|--------|-------|-----|-------------|
| `PUT`  | `/api/auth/profile` | Any user | Update bio. Body: `{ bio }` |
| `POST` | `/api/auth/profile/avatar` | Any user | Upload avatar. Multipart, field: `avatar` |
| `GET`  | `/api/auth/profile/<username>` | Any user | Public profile info |

### Announcements

| Method | Route | Who | Description |
|--------|-------|-----|-------------|
| `GET`    | `/api/announcements/` | Any user | List all (pinned first) |
| `POST`   | `/api/announcements/create` | Admin | Create. Body: `{ title, content, is_pinned }` |
| `PUT`    | `/api/announcements/<id>/` | Admin | Edit |
| `DELETE` | `/api/announcements/<id>/` | Admin | Delete |

### Chat — REST

| Method | Route | Who | Description |
|--------|-------|-----|-------------|
| `GET`    | `/api/chat/channels/` | Any user | List all channels |
| `POST`   | `/api/chat/channels/create` | Admin | Create channel. Body: `{ name, description }` |
| `DELETE` | `/api/chat/channels/<id>/delete` | Admin | Delete channel + all its messages |
| `GET`    | `/api/chat/channels/<id>/messages/` | Any user | Load message history |
| `POST`   | `/api/chat/channels/<id>/messages/send` | Members + Admins | Send text message |
| `DELETE` | `/api/chat/messages/<id>/delete` | Author or Admin | Delete a message |
| `POST`   | `/api/chat/messages/<id>/react` | Members + Admins | Toggle emoji reaction. Body: `{ emoji }` |
| `POST`   | `/api/chat/channels/<id>/upload` | Members + Admins | Upload file (max 8MB). Multipart, field: `file` |

### Chat — WebSocket

| | URL |
|-|-----|
| Connect | `ws://localhost:5173/ws/chat/<channel_id>/?token=<jwt>` |

**Server → browser:**
```jsonc
{ "type": "message", "id": 1, "content": "hello", "username": "angel",
  "role": "admin", "avatar_url": "/media/avatars/...", "created_at": "...",
  "file_url": null, "reactions": [] }

{ "type": "typing", "username": "angel" }
{ "type": "typing_stop", "username": "angel" }
{ "type": "reaction_update", "message_id": 1, "reactions": [...] }
```

**Browser → server:**
```jsonc
{ "content": "hello" }
{ "type": "typing", "content": "" }
{ "type": "typing_stop", "content": "" }
```

## ❓ Troubleshooting

**Django admin has no CSS / looks unstyled**
```bash
cd backend && source venv/bin/activate
python manage.py collectstatic    # type "yes"
daphne -p 8000 core.asgi:application
```

**"table does not exist" or database errors**
```bash
python manage.py migrate
```

**Missing Python packages after pulling**
```bash
source venv/bin/activate
pip install -r ../requirements.txt
```

**Missing JavaScript packages**
```bash
npm install
```

**Chat shows "Connecting..." forever**
- Make sure you're using `daphne`, NOT `manage.py runserver`
- Make sure at least one Channel exists (create from Portal sidebar or Django admin)
- Log out and back in — JWT token may have expired
- Check browser console (F12) for WebSocket errors

**Images not showing in chat**
- Make sure daphne is running — media files are served by Django on port 8000
- The `backend/media/` folder is created automatically on first upload

**Typing indicator not working**
- Both users must be in the same channel at the same time
- Restart daphne after any changes to `consumers.py`

**Admin account can't log into `/admin`**
- Run the one-time shell fix in the Django Admin Access section above
